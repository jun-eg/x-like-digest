# ADR design-doc-0004: 入口の「5 件とも未取得なら次のページも取る」だけでは止め方が決まらず、技術の要件定義 9-13 を指す一言を足した

- **Status**: 有効
- **Date**: 2026-11-02
- **対象**: docs/agent/design-doc.md — 6 スコープ内「入口」
- **出典**: issue #63（親 #57）、PR #64 の pr-reviewer 1 周目、利用者の決定（2026-11-02）

## それまでの結論

[ADR design-doc-0003](0003-x-api-pull-entry.md) が入れた入口の文は、「1 回に取るのは最新 5 件で、5 件とも未取得なら次のページも取る。」だった。

## 何が起きたか

「未取得」の定義と、次のページを取り続ける止め場所が文に無かった。技術の要件定義 9-13 で、前回の取得で上位にあった `post_id` に行き当たるまで最大 10 ページめくり、当たらなければ定期の取得を止め、初回は 1 ページを覚えるだけで取り込まないと決めた。初回は「5 件とも未取得」の字義どおりには次のページへ進まないので、文だけでは読み違える。

## 新しい結論

入口の文の末尾に「止め方と上限は技術の要件定義 9-13。」を足した。取得の間隔、最新 5 件、費用の見積もりは変えていない。

## 影響

- 6 スコープ内「入口」に一言を足した。更新ログに 1 行足した
- 技術の要件定義 9-13 と ADR tech-requirements-0008 が止め方を持つ
